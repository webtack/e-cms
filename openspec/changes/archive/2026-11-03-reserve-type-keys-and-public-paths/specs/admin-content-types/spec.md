# Spec Delta

## ADDED Requirements

### Requirement: Помилки зарезервованого ключа й колізій slug у формах типу
Форма створення типу SHALL відхиляти ключ зі списку зарезервованих і показувати помилку біля поля ключа. Форми створення й редагування типу SHALL відхиляти slug, що збігається зі slug запису виду `page` або зі зарезервованим шляхом сайту, і показувати помилку біля поля slug; решта введених значень SHALL лишатися у формі. Для розділів сторінок і блоків ключ SHALL перевірятися так само, як для контенту. Повідомлення SHALL відображатися мовою інтерфейсу.

#### Scenario: Зарезервований ключ
- **WHEN** користувач вводить ключ `pages` (або `content`, `blocks`, `fields`, `menus`, `errors`) у формі створення типу будь-якого розділу й надсилає форму
- **THEN** тип не створено, біля поля ключа показано помилку «Цей ключ зарезервований», введене лишається у формі

#### Scenario: Slug збігається зі сторінкою
- **WHEN** користувач вводить slug `about`, а запис виду `page` уже має slug `about`
- **THEN** тип не створено, біля поля slug показано помилку

#### Scenario: Slug збігається зі зарезервованим шляхом
- **WHEN** користувач вводить у формі редагування типу slug `admin`
- **THEN** зміну не збережено, біля поля slug показано помилку

#### Scenario: Збереження без зміни slug
- **WHEN** наявний тип зі slug, що колись збігся зі slug сторінки, зберігається з незміненим slug і новою назвою
- **THEN** зміну збережено
