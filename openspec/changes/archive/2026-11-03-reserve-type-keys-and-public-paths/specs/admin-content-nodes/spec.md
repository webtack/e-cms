# Spec Delta

## ADDED Requirements

### Requirement: Помилка колізії slug сторінки у формі запису
Форми створення й редагування запису виду `page` SHALL відхиляти slug, що збігається зі slug типу виду `content` або зі зарезервованим шляхом сайту, і показувати помилку біля поля slug; решта введеного SHALL лишатися у формі. Для записів видів `content` і `block` ця перевірка НЕ діє. Автоматично утворений slug сторінки SHALL уникати таких збігів додаванням числового суфікса, тож помилка виникає лише для явно введеного slug.

#### Scenario: Slug сторінки збігається зі slug типу
- **WHEN** користувач вводить у формі сторінки slug `news`, а тип виду `content` має slug `news`
- **THEN** сторінку не збережено, біля поля slug показано помилку

#### Scenario: Slug сторінки збігається зі зарезервованим шляхом
- **WHEN** користувач вводить у формі редагування сторінки slug `login`
- **THEN** зміну не збережено, біля поля slug показано помилку

#### Scenario: Автоматичний slug без збігу
- **WHEN** користувач залишає slug порожнім і вводить `title` «Admin»
- **THEN** сторінку створено зі slug `admin-2`

#### Scenario: Запис content зі slug типу
- **WHEN** користувач вводить у формі запису типу `content` slug `news`, а тип має slug `news`
- **THEN** запис збережено
