# Spec Delta

## ADDED Requirements

### Requirement: Вибірковий запуск окремих e2e-спеків
Система SHALL дозволяти запускати один або кілька e2e-спеків за шляхом файла командою `npm run test:e2e -- e2e/<файл>.spec.js` на хості, і SHALL виконувати для такого запуску ту саму підготовку, що й для повного (зокрема скидання мови адміністратора на англійську).

#### Scenario: Запуск одного спека
- **WHEN** розробник виконує `npm run test:e2e -- e2e/admin-page-types.spec.js` при запущених контейнерах
- **THEN** виконуються лише тести з цього файла, а команда завершується з кодом їхнього результату

#### Scenario: Підготовка виконується і для вибіркового запуску
- **WHEN** у `users.locale` адміністратора лишилась `uk`, а розробник запускає один спек
- **THEN** до першого тесту мова адміністратора стає `en`, як і при повному запуску
