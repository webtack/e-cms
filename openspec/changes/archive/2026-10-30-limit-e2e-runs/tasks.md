# Tasks

## 1. Правила запуску

- [x] 1.1 Оновити розділ «Playwright (e2e)» у `CLAUDE.md`: вибірковий запуск під час роботи (`npm run test:e2e -- e2e/<спек>`), повний прогін лише після правок спільного коду (перелік «спільного коду» в тому ж розділі); перевірка: розділ читається однозначно, команди збігаються з `docs/e2e-testing.md`
- [x] 1.2 Додати в `openspec/config.yaml` у `rules.tasks` правило: завдання перевіряють лише спек зміненої області, повний `npm run test:e2e` — лише в завданні, що чіпає спільний код; новий спек додає рядок у таблицю відповідності; перевірка: `openspec instructions tasks --change limit-e2e-runs --json` показує нове правило, YAML валідний

## 2. Перевірка та документація

- [x] 2.1 Переконатися, що вибірковий запуск працює з `globalSetup`: виставити `users.locale` адміністратора в `uk` і виконати `npm run test:e2e -- e2e/smoke.spec.js` (мова стає `en`), потім `npx playwright test --list e2e/admin-page-types.spec.js` показує лише його тести; перевірка: обидві команди дають очікуваний результат
- [x] 2.2 Додати в `docs/e2e-testing.md` (українською) розділ «Коли запускати e2e»: два рівні запуску, команди вибіркового запуску, таблицю «область → спек», пояснення, чому не `--only-changed`; перевірка: відносні посилання валідні, таблиця охоплює всі спеки з `e2e/`
