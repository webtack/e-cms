- [x] 2.2 Додати в `config/content.php` ключ `richtext.iframe_allow` (білий список назв дозволів: `accelerometer`, `autoplay`, `clipboard-write`, `encrypted-media`, `fullscreen`, `gyroscope`, `picture-in-picture`, `web-share`); перевірка: `tinker` повертає список.
- [x] 2.3 Створити `App\Content\StyleAttributeSanitizer` (`AttributeSanitizerInterface`: на `span`, `p`, `h2`–`h4`, `blockquote`, `li` лишає лише `text-align`, `color`, `background-color` зі значеннями `#rgb`/`#rrggbb`/`rgb(r, g, b)`; інше й порожній результат відкидає) з PHPDoc англійською та `@example`; перевірка: тести сценаріїв spec «Вирівнювання», «Колір тексту й фону», «Небезпечний style», «style на недозволеному тегу» у `tests/Feature/Content/HtmlSanitizerTest.php` проходять.
- [x] 2.4 Розширити `App\Content\HtmlSanitizer`: `span` перенести з `UNWRAPPED_TAGS` у дозволені, підключити `StyleAttributeSanitizer`, дозволити `iframe` (`src`, `width`, `height`, `title`, `allowfullscreen`, `allow` з очищенням `IframeAllowSanitizer` за `richtext.iframe_allow`) з перевіркою `src` (`https`, точний збіг хоста й префікс шляху з конфігом; інакше тег прибрано повністю) і примусовими `sandbox` та `loading="lazy"`; оновити PHPDoc класу; перевірка: тести сценаріїв «Фрейм з дозволеного хоста зберігається» й «Фрейм з чужого хоста або не https прибирається» (зокрема Google Drive, Google Forms (`viewform?embedded=true`) та Facebook-плагін зберігаються, `facebook.com/some.page` поза префіксом прибирається, `youtube.com.evil.example`, `//host`, `javascript:`, `data:`), а також наявні сценарії очищення проходять: `docker compose exec app php artisan test --filter=HtmlSanitizer`.
- [x] 2.5 Перевірити, що `HtmlSanitizer::text()` не враховує `iframe` у видимому тексті й що `RichTextType::isBlank` для значення лише з `iframe` повертає `false` (фрейм — вміст); додати тест у `tests/Feature/Content/RichTextFieldTypeTest.php`; перевірка: `docker compose exec app php artisan test --filter=RichText` проходить.
- [x] 2.6 Віддати `content.richtext.iframe_hosts` клієнту у спільних Inertia-пропсах (`HandleInertiaRequests`: `richtext.iframeHosts`); перевірка: Feature-тест спільних пропсів (або наявний файл тестів оболонки) бачить список; `docker compose exec app vendor/bin/pint --dirty --format agent` і `docker compose exec app php artisan test` зелені.
- [x] 2.7 Оновити `docs/content-values.md` (розділ санітизації: `span`/`style`, правила значень, `iframe`, ключ конфігурації `richtext.iframe_hosts`, `sandbox`); перевірка: посилання в документі працюють, `docs/README.md` чинний.
