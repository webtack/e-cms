## ADDED Requirements

### Requirement: Опис поля
Поле типу контенту SHALL мати необов'язковий текстовий опис — інструкцію для редактора запису. Форми створення й редагування поля SHALL містити багаторядкове поле «Опис» довжиною до 1000 символів; порожнє значення (також з самих пробілів) зберігається як відсутній опис. Опис SHALL дозволяти змінювати і для системних полів. Перевищення довжини SHALL відхилятися помилкою біля поля «Опис» без втрати введеного. Опис не впливає на значення поля, його перевірку й зберігання. Форми запису показують опис після підпису поля.

#### Scenario: Створення поля з описом
- **WHEN** користувач створює поле й вводить опис
- **THEN** поле збережено з описом, а форма редагування поля показує його

#### Scenario: Очищення опису
- **WHEN** користувач стирає опис у формі редагування поля й зберігає
- **THEN** опису в поля немає

#### Scenario: Занадто довгий опис
- **WHEN** користувач вводить опис довший за 1000 символів і зберігає
- **THEN** збереження відхилено, біля поля «Опис» показано помилку, введене збережено

#### Scenario: Системне поле
- **WHEN** користувач редагує системне поле `title` і задає опис
- **THEN** опис збережено, інші обмеження системного поля лишаються чинними

#### Scenario: Поле без опису
- **WHEN** поле створено без опису
- **THEN** воно зберігається без опису, а форма запису не показує допоміжного тексту
