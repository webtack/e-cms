The structural reference is the changes `add-taxonomy-core` and `add-taxonomy-admin` (they are already in `main`): the models, `TermWriter`/`TermTree`, `TermOwner`, `VocabularyController`/`TermController`, `Pages/Admin/Taxonomy/*`.

## 1. Schema and models

- [x] 1.1 The migration `create_menus_tables` (`menus`, `menu_items`, `menu_item_translations` per [design.md](design.md), the self-reference in a separate `Schema::table`, `RESTRICT` on all foreign keys except the translations) and the models `Menu`, `MenuItem`, `MenuItemTranslation` with the relations (`Menu::items()`, `MenuItem::menu()/parent()/children()/translations()`) and English JSDoc/PHPDoc; check `docker compose exec app php artisan migrate`, `migrate:rollback` and a repeated `migrate`, and the full `docker compose exec app php artisan test --compact` (the migration changes the DB schema, so this is the only place of the full PHP run in this change).

- [x] 1.3 `App\Menus\MenuUrl` (`isValid`, `isExternal`) and its use in the model; check `docker compose exec app php artisan test --compact --filter=MenuUrlTest` (relative `/`, `#`, `?`; absolute `http`, `https`, `mailto`, `tel`; rejection of `javascript:`, `data:`, `about`, `//host`, spaces and control characters; length 2048; `isExternal` for `true`, `false`, `null`).
