# Proposal

## Why

Після збереження змін адмінка кидає користувача зі форми на список, тож щоб підправити ще щось або перевірити результат, форму доводиться відкривати знову. Рядок запису в таблиці не має швидкого переходу на публічну сторінку, а головна сторінка сайту не віддає мета-даних із налаштувань сайту (опис і зображення для пошуковиків і соцмереж).

## What Changes

- Після успішного **оновлення** (форми редагування) користувач лишається на тій самій сторінці з toast «успіх» замість переходу на список. Стосується всіх форм редагування адмінки: тип контенту, тип сторінки, тип блоку, поле типу, запис, меню, пункт меню, словник, термін, роль, користувач. Вкладки налаштувань типу («Відображення», «Значення», «SEO») та налаштування сайту вже лишаються на сторінці — поведінку лише фіксуємо в специфікації.
- Створення й видалення не змінюються (після створення — перехід на список, як і раніше).
- У меню «⋮» рядка запису (типи `content` і `page`) з'являється пункт «Перегляд» — посилання на публічну адресу запису в новій вкладці (як кнопка «Перегляд» у формі редагування). Для блоків і для типів `content` без публічного slug пункту немає.
- Публічні сторінки (головна, сторінки, записи, 404) виводять у `<head>` мета-дані (`<title>`, `meta description`, `og:image`) за ланцюжком: власні `meta_*` запису → поля, вибрані в налаштуваннях типу → налаштування сайту (назва, опис, велике лого, запасно мале). Кожне значення береться окремо.
- На вкладці «Відображення» типів `content` і `page` у «Публічному відображенні» з'являється підблок «Мета-дані»: вибір поля для заголовка (рядок), опису (текст / форматований текст) та зображення (зображення / відео YouTube). Для множинних полів береться перше значення; з опису вирізається HTML, а текст скорочується до 160 символів; для YouTube береться скриншот відео, якщо він є. Зберігається в `settings.public.meta`. Для типів `block` підблоку немає.

## Capabilities

### New Capabilities

Немає.

### Modified Capabilities

- `admin-shell`: нова вимога — успішне збереження форми редагування лишає користувача на цій самій сторінці.
- `admin-content-types`: «Збереження змін типу» — користувач лишається на формі, а не переходить до списку; «Секція «Публічне відображення»…» — підблок «Мета-дані».
- `admin-page-types`: «Редагування типу сторінки» — те саме.
- `admin-block-types`: «Редагування типу блоку» — те саме.
- `admin-content-fields`: «Збереження змін поля» — користувач лишається на формі поля.
- `admin-content-nodes`: «Збереження змін запису» (лишається на формі) і «Створення запису з таблиці» (пункт «Перегляд» у меню рядка).
- `public-site`: нова вимога — ланцюжок мета-даних: запис → вибрані поля типу → налаштування сайту.

## Impact

- Backend: `update`-методи контролерів `app/Http/Controllers/Admin/` (`ContentTypeController`, `ContentFieldController`, `ContentNodeController`, `MenuController`, `MenuItemController`, `VocabularyController`, `TermController`, `RoleController`, `UserController`) → `back()`; `ContentNodeController::row()` додає публічну адресу рядка; `App\Theme\PublicData` і новий резолвер мета-даних; `PublicDisplaySettings`, `UpdateContentTypeDisplayRequest`, `ContentType::assertValidPublicSettings()`, `ContentTypeDisplayController` — ключ `settings.public.meta`; `PublicDisplaySettingsSection.tsx` / `TypeDisplayForm.tsx` — підблок «Мета-дані»; `config/content.php` — довжина опису.
- Frontend: `resources/js/Components/Admin/ContentNodes/ContentNodeRowActions.tsx`, `resources/js/Pages/Admin/ContentNodes/Index.tsx`; шаблон `themes/default/views/html.blade.php` (за потреби).
- Тести: оновити Feature-тести й e2e-спеки, що очікують редірект після оновлення; додати тести пункту «Перегляд» і мета-даних (ланцюжок, поля типу, YouTube, скорочення); переклад «Перегляд» уже існує.
- Docs: `docs/admin-content-types.md`, `docs/admin-page-types.md`, `docs/admin-block-types.md`, `docs/admin-content-fields.md`, `docs/admin-content-nodes.md`, `docs/admin-menus.md`, `docs/admin-taxonomy.md`, `docs/admin-roles.md`, `docs/admin-users.md`, `docs/admin-shell.md`, `docs/public-site.md`, `docs/theme-templates.md`, `docs/e2e-testing.md` (за потреби).

## Припущення

- «Усі форми» = усі форми редагування адмінки, а не лише типів контенту; створення й видалення лишаються як були.
- «image» в налаштуваннях сайту = велике лого (`logo_large`), якщо його немає — мале.
- Сторінки успадковують опис і зображення сайту (рішення власника); `<title>` уже має запасний варіант — назву сайту.
- Максимальна довжина мета-опису — 160 символів (поширена межа для сніпетів пошуковиків), задається в конфігурації; скорочення по межі слова з «…». Для заголовка скорочення не застосовується.
- Мета-поля вибираються серед доданих полів (`is_system = false`) за типом значення; для сторінок `page` підблок теж доступний, для `block` — ні (власної адреси немає).
