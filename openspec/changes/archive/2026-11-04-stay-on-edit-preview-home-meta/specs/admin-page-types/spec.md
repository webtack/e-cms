# Spec Delta

## MODIFIED Requirements

### Requirement: Редагування типу сторінки
Адмінка SHALL мати форму `/admin/page-types/{key}/edit` з полями назви, батьківського типу й опису та ключем лише для читання. Збереження SHALL змінювати лише назву, батьківський тип і опис, а користувач SHALL лишатися на формі редагування; `key` і `kind` не змінюються. Батьківським не можна обрати сам тип чи його нащадка. Для ключа, якого немає серед типів виду `page` (зокрема ключа типу `content` чи `block`), усі маршрути розділу SHALL відповідати 404, а `/admin/content-types/{key}/**` для типу `page` — також 404.

#### Scenario: Успішне збереження
- **WHEN** користувач змінює назву типу сторінки й зберігає
- **THEN** назву оновлено, користувач лишився на формі редагування типу з повідомленням

#### Scenario: Тип іншого виду
- **WHEN** користувач відкриває `/admin/page-types/{key}/edit` для ключа типу виду `content`
- **THEN** відповідь 404

#### Scenario: Розділ контенту не відкриває сторінки
- **WHEN** користувач відкриває `/admin/content-types/{key}/edit` для ключа типу виду `page`
- **THEN** відповідь 404

#### Scenario: Нащадок як батько
- **WHEN** запит редагування вказує як батька нащадка типу
- **THEN** збереження відхилено з помилкою біля поля батьківського типу
