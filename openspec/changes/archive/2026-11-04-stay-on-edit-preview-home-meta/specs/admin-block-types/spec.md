# Spec Delta

## MODIFIED Requirements

### Requirement: Редагування типу блоку
Адмінка SHALL мати форму `/admin/block-types/{key}/edit` з полями назви, батьківського типу й опису та ключем лише для читання. Збереження SHALL змінювати лише назву, батьківський тип і опис, а користувач SHALL лишатися на формі редагування; `key` і `kind` не змінюються. Батьківським не можна обрати сам тип чи його нащадка. Для ключа, якого немає серед типів виду `block` (зокрема ключа типу `content` чи `page`), усі маршрути розділу SHALL відповідати 404, а `/admin/content-types/{key}/**` і `/admin/page-types/{key}/**` для типу `block` — також 404.

#### Scenario: Успішне збереження
- **WHEN** користувач змінює назву типу блоку й зберігає
- **THEN** назву оновлено, користувач лишився на формі редагування типу з повідомленням

#### Scenario: Тип іншого виду
- **WHEN** користувач відкриває `/admin/block-types/{key}/edit` для ключа типу виду `content` чи `page`
- **THEN** відповідь 404

#### Scenario: Інші розділи не відкривають тип блоку
- **WHEN** користувач відкриває `/admin/content-types/{key}/edit` або `/admin/page-types/{key}/edit` для ключа типу виду `block`
- **THEN** відповідь 404

#### Scenario: Нащадок як батько
- **WHEN** запит редагування вказує як батька нащадка типу
- **THEN** збереження відхилено з помилкою біля поля батьківського типу
