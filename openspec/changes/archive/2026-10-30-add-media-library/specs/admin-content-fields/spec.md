# Spec Delta

## ADDED Requirements

### Requirement: Налаштування типів і розміру для полів «зображення» і «файл»
Коли у формі створення чи редагування поля вибрано тип значення `image` або `file`, форма SHALL показувати налаштування: вибір дозволених типів файлів (серед типів профілю цього типу поля) і максимальний розмір у кілобайтах. Без вибору типів і без розміру діють правила всього профілю. Для інших типів ці налаштування SHALL не показуватися. Сервер SHALL відхиляти тип поза профілем і розмір понад ліміт профілю з помилкою біля відповідного елемента, незалежно від стану форми. Зміна налаштувань SHALL бути дозволена і для поля, що має збережені значення, і не змінювати вже збережені значення.

#### Scenario: Налаштування з'являються лише для файлових типів
- **WHEN** користувач вибирає тип `image` у формі створення поля
- **THEN** з'являються вибір типів файлів зі списку типів профілю `image` і поле максимального розміру, а для типу `string` їх немає

#### Scenario: Збереження налаштувань
- **WHEN** користувач створює поле `image`, вибирає лише PNG і вказує максимальний розмір 1024 КБ
- **THEN** поле збережено, його налаштування містять `image/png` і `1024`, а при відкритті редагування вони вибрані

#### Scenario: Без налаштувань
- **WHEN** користувач створює поле `file`, не вибравши типів і не вказавши розміру
- **THEN** поле збережено без обмежень понад профіль `document`

#### Scenario: Тип поза профілем
- **WHEN** запит створює поле `image` з типом `application/pdf`
- **THEN** поле не створено, біля вибору типів показано помилку

#### Scenario: Розмір понад ліміт профілю
- **WHEN** запит створює поле `image` з розміром, більшим за ліміт профілю
- **THEN** поле не створено, біля поля розміру показано помилку

#### Scenario: Звуження для поля зі значеннями
- **WHEN** користувач звужує дозволені типи поля, що вже має збережені значення
- **THEN** зміни збережено, наявні значення не змінюються
